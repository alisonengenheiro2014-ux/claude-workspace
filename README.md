# Claude

Workspace pessoal para experimentos e projetos com Claude Code.

## Sobre

Este repositório serve como ponto de partida para explorar o Claude Code — a CLI oficial da Anthropic para assistência em tarefas de engenharia de software.

## Como usar

1. Instale o Claude Code
2. Abra esta pasta no terminal
3. Execute `claude` para iniciar uma sessão interativa
