# Claude

Workspace pessoal para experimentos e projetos com Claude Code.

## Sobre

Este repositório serve como ponto de partida para explorar o Claude Code — a CLI oficial da Anthropic para assistência em tarefas de engenharia de software.

## Pré-requisitos

- [Node.js](https://nodejs.org) 18 ou superior
- Conta na [Anthropic](https://console.anthropic.com) com chave de API

## Como usar

1. Instale o Claude Code:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
2. Configure sua chave de API:
   ```bash
   export ANTHROPIC_API_KEY=sua-chave-aqui
   ```
3. Abra esta pasta no terminal e execute:
   ```bash
   claude
   ```
